# Robert Parlee Style Guide

## Direction

Warm Americana with a classic rock backbone: road-worn, confident, and professional without looking like a generic black musician template.

## Palette

- `--ink`: #211a16 - primary text
- `--coffee`: #3b241a - deep brown surfaces
- `--leather`: #7b4a2d - earthy accent
- `--amber`: #d79b45 - highlight and CTA color
- `--steel`: #607d8b - cool counterpoint
- `--paper`: #f6efe3 - page background
- `--cream`: #fff8ed - cards and panels

## Typography

- Display: `Fraunces`, serif
- Body: `Source Sans 3`, sans-serif

Fonts are loaded from Google Fonts in the static HTML. If a fully self-hosted font setup is needed later, place font files in `site/assets/fonts/` and update `variables.css`.

## Components

- Hero panels use large editorial typography, textured gradients, and clear booking/music CTAs.
- Cards should feel tactile: cream backgrounds, soft borders, slight lift on hover.
- Buttons should be high-contrast and verb-led: Book Robert, Listen Now, Download EPK.
